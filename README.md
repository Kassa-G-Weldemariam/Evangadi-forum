# Evangadi Forum (Full-Stack Web Application)

A full-stack forum application that allows users to post questions and interact with content. This project was built to practice frontend-backend integration and database-driven development.

## 🚀 Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MySQL 

## 🎯 Features
- User registration and login
- Create and view posts/questions
- Backend API handling
- Database storage for persistent data
- Dynamic frontend-backend communication

## 🧠 Concepts Practiced
- REST API development
- Express routing and middleware
- Database connection and queries
- Authentication basics (if implemented)
- Client-server architecture

## ▶️ How to Run

1. Clone the repository
2. Install dependencies
